# chinese-text-polisher

中文文本润色与图书正文合规审校 Skill（Agent 技能包）。

## 功能

- **润色改写**：在不增删事实、不改变原意的前提下，把文字调整为平实、流畅、客观的现代汉语。
- **合规排查**：对照 A/B/C/D 四级禁止清单，定位书稿正文、案例、习题、图表说明中的真实性风险、语法逻辑错误、风格禁句与体例问题，给出修改方向。

## 目录结构

## 适用文稿

大众图书、商业实战图书、专业教材、操作手册及其正文、案例、习题、图表说明、参考资料。

清单源自《图书正文禁止与规避事项清单 V2.0》，共 260 条（A01–D64）。
