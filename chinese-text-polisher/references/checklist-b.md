# B级清单｜必须消除：现代汉语语法、逻辑与上下文硬错误

> 本文件是 chinese-text-polisher 技能的 B 级排查分册。B 级为现代汉语语法、逻辑关系和上下文一致性上的硬错误，润色时须先修正结构与关系，再谈风格。
>
> 目录：
>
> - B1 句子成分残缺与结构失当（B01–B12）
> - B2 成分搭配、语序与修饰关系（B13–B26）
> - B3 否定、关联词、句式结构与逻辑关系（B27–B40）
> - B4 指代、省略、歧义及表达完整性（B41–B49）
> - B5 上下文、跨节跨章与论证一致性（B50–B67）

## B1．句子成分残缺与结构失当

| 编号 | 禁止事项 | 违规示例 | 违规原因与判定说明 |
|---|---|---|---|
| B01 | 禁止“通过／经过／由于／随着……使／让……”导致全句无明确陈述主体。 | “通过对案例的分析，使读者理解了这一问题。” | 介词结构遮蔽主语，后续谓语无明确主语；须按整句结构判定。 |
| B02 | 禁止主语在必要语境中缺失，以致动作执行者无法确定。 | “项目由编辑组审核，完成后再进行修改。” | “完成”“进行修改”的主体不明，可能出现责任错配。 |
| B03 | 禁止谓语残缺，导致句子只留下名词堆积或半截判断。 | “数字教材的核心价值，在于教学资源的整合，以及课堂活动。” | “以及”后内容与前面“在于”的支配结构未合理衔接。 |
| B04 | 禁止及物动词缺少必要宾语。 | “编辑应重点关注并及时处理。”（没有交代处理什么） | “处理”的对象不明，造成谓语语义不完整。 |
| B05 | 禁止带双宾语或兼语结构时漏掉必要对象。 | “老师要求完成实验，并于周五提交。”（无前文可追溯的执行者） | 谁完成、谁提交不明，影响实际指令。 |
| B06 | 禁止定语缺失导致名词的类别、范围或所指无法辨识。 | “对上述对象进行分析。”（前文涉及四类不同对象） | 名词虽存在，但必要限定缺失造成指称不确定。 |
| B07 | 禁止状语缺失造成执行方式、时点或适用条件不可判定。 | “系统在截止时间后自动提交材料。”（截止时间指哪个任务未交代） | 时间性约束没有具体所指，可能改变流程结果。 |
| B08 | 禁止补语缺失造成结果、程度、方向或完成条件悬空。 | “编辑把这段文字修改得。” | “得”字结构未闭合，句法直接残缺。 |
| B09 | 禁止“把”字句中缺少有效处置关系。 | “把这个问题认为很重要。” | “把”字句要求合适的处置性动词结构，此处搭配不成立。 |
| B10 | 禁止“被”字句中施事、受事关系混乱。 | “用户被平台提交了申请。” | 动作方向倒置，语义角色错误。 |
| B11 | 禁止使用悬空的动词性成分，致使句子无谓语中心。 | “针对教师需要备课、评价和管理的现实问题。” | 单独成句时只有介词性结构，缺乏完整陈述。 |
| B12 | 禁止机械补全本来合法的省略句、祈使句、无主句或名词谓语句，造成病句。 | 将“请保存文件。”强改成“你这个读者请保存文件。” | 现代汉语不存在“每句六种成分必须齐全”的规则；过度补成分损害自然语法。 |

## B2．成分搭配、语序与修饰关系

| 编号 | 禁止事项 | 违规示例 | 违规原因与判定说明 |
|---|---|---|---|
| B13 | 禁止主语与谓语在语义选择上不搭配。 | “这份报告发生了显著提高。” | “报告”无法与“发生提高”构成合适陈述关系。 |
| B14 | 禁止动词与宾语搭配错误。 | “提高了知识储备和工作态度。” | “提高”与“工作态度”语义关系失当。 |
| B15 | 禁止修饰语与中心语搭配错误。 | “一份强烈的解决方案。” | “强烈”与“解决方案”搭配不自然，无法准确传达性质。 |
| B16 | 禁止主宾语意义类别不对应的判断句。 | “这本教材的目标是帮助学生的能力。” | “目标”不能直接与“能力”构成该谓语结构。 |
| B17 | 禁止同一谓语统摄不相容的并列宾语。 | “开展了教学改革、专家和平台建设。” | “开展”适配“教学改革”，却不能照样统摄“专家”。 |
| B18 | 禁止不同结构或不同语义层级的成分硬性并列。 | “重点研究用户需求、如何变现和市场的未来。” | 并列项分别为名词、问句结构与含混名词短语，层级失衡。 |
| B19 | 禁止定语与中心语距离错位导致误修饰。 | “讨论了新开发的有关学生的课程评价系统。” | “新开发的”指向与“有关学生的”范围不清。 |
| B20 | 禁止多重状语顺序错乱并造成歧义。 | “老师仔细地昨天在办公室检查了论文。” | 时间、处所和情态状语位置失当，破坏语流和理解。 |
| B21 | 禁止多层定语顺序混乱，导致限定关系不明。 | “一份三年最新高校教师调查报告。” | 时间、对象与性质限定关系不清。 |
| B22 | 禁止主语在句中无依据地偷换。 | “课程上线后，教师可以追踪学习进度，也能自动生成测试题。” | “能生成测试题”的执行主体可能从教师滑向系统。 |
| B23 | 禁止主动、被动关系误置。 | “教材由作者被出版社审定。” | 介词“由”与“被”的结构关系互相冲突。 |
| B24 | 禁止数量词与名词类别不匹配。 | “三条教师”“两位数据”“一颗建议”。 | 量词不符合所指名词的通常计量方式。 |
| B25 | 禁止“的、地、得”混用造成语法或语义错误。 | “快速的完成任务”“写地很清楚”。 | 定中、状中及述补结构的标记混乱。 |
| B26 | 禁止“是否／能否／有无”等双面词与单面结论不对应。 | “能否完成项目，取决于团队执行力强。” | 前半涉及两种可能，后半只呈现一端，判断结构不对称。 |

## B3．否定、关联词、句式结构与逻辑关系

| 编号 | 禁止事项 | 违规示例 | 违规原因与判定说明 |
|---|---|---|---|
| B27 | 禁止多重否定造成实际意思与预期相反。 | “为避免不再发生类似错误，必须严格检查。” | “避免不再”在逻辑上接近避免停止发生，偏离本意。 |
| B28 | 禁止否定范围不明确。 | “所有教师没有参加这次培训。” | 可能表示“无一参加”，也可能表示“并非全部参加”。 |
| B29 | 禁止“不能不”“不得不”“不无”等复合否定被误读或误用。 | “公司不能不拒绝这项合作。”（意图是接受合作） | 多层否定改变最终命题真值。 |
| B30 | 禁止关联词前后语义关系不成立。 | “虽然报名人数增加，因此课程质量提高。” | 转折结构与因果结构交叉，且没有因果证据。 |
| B31 | 禁止关联词缺项导致复句结构失衡。 | “既要提高速度，也保证准确率，更培养能力。” | 多项关联关系混乱，成分对称性被破坏。 |
| B32 | 禁止把递进、转折、并列、条件、因果关系互相冒充。 | “因为教材增加了配图，所以学生一定学得更好。” | 配图增加并不足以推出学习结果。 |
| B33 | 禁止充要条件混淆。 | “只要有了大模型，就一定能完成任何科研任务。” | 将可能帮助任务的条件写成充分条件。 |
| B34 | 禁止将必要条件误判为充分条件。 | “只要核对了参考文献，全文内容就一定正确。” | 单一审查环节不能保证全部事实无误。 |
| B35 | 禁止论点自我循环论证。 | “这是一种高效方法，因为它能高效解决问题。” | 结论被重复当作理由，未增加证据。 |
| B36 | 禁止偷换核心概念或比较口径。 | “模型回答速度快，因此回答质量更高。” | 用速度代替质量评价，概念发生漂移。 |
| B37 | 禁止以单个案例推出群体性结论。 | “一名学生使用后成绩提高，因此所有学生都会受益。” | 个案不能代表总体，样本外推不成立。 |
| B38 | 禁止比较结构中缺失基准或比较维度。 | “这种方法效率提高了3倍。”（未交代相对谁、按什么指标） | 比较对象、指标或倍数口径不明，读者无法验证。 |
| B39 | 禁止先后顺序混乱、倒因为果或无法闭合的时间线。 | “2025年发布的新政策促成了2023年的课程改革。” | 时间关系冲突，因果顺序不成立。 |
| B40 | 禁止使用有逻辑漏洞的反问句强行制造结论。 | “难道用了新工具还会效率下降吗？” | 反问句掩盖实际存在的学习成本和失败情形。 |

## B4．指代、省略、歧义及表达完整性

| 编号 | 禁止事项 | 违规示例 | 违规原因与判定说明 |
|---|---|---|---|
| B41 | 禁止“它／其／这／该／上述／前者／后者”缺乏唯一指向。 | “教师将课件上传到平台，它会自动更新。” | “它”可能指课件，也可能指平台。 |
| B42 | 禁止长距离指代跨越多个可能先行词。 | “前文介绍了平台、插件、模型和知识库。它最关键的功能是……” | 先行词不唯一，跨段追踪容易失效。 |
| B43 | 禁止省略重复成分后引起句法歧义。 | “王老师通知李老师和他的学生。” | “他的学生”归属不清。 |
| B44 | 禁止范围不明的“等／等等／相关／相应／若干／一些”。 | “上传相关材料等即可。” | 任务所需输入未确定，属于关键行动信息缺失。 |
| B45 | 禁止“分别”“依次”“逐一”缺少可对应的对象或顺序。 | “甲乙两组分别完成三项实验。” | 两组与三项如何对应不明确。 |
| B46 | 禁止同一句存在两种实质相反的合理理解。 | “我们邀请了三位老师的学生。” | 可解释为三位教师所带学生，或三名属于老师的学生。 |
| B47 | 禁止无理由的省略主语造成作者、读者、软件、机构之间角色错位。 | “单击‘导出’，随后保存为PDF，并会自动寄送给客户。” | 人的动作与系统动作混杂。 |
| B48 | 禁止把尚未定义的缩写、符号、代词当作已知信息直接使用。 | “完成ETL后再进入RAG评估。”（面向零基础读者且无解释） | 理解所需的前置语义缺失。 |
| B49 | 禁止指令性语句中的执行对象、对象范围或终止条件缺失。 | “全部处理好后提交。” | “全部”指什么、何为“处理好”均无判据。 |

## B5．上下文、跨节跨章与论证一致性

| 编号 | 禁止事项 | 违规示例 | 违规原因与判定说明 |
|---|---|---|---|
| B50 | 禁止同一概念在前后文中未经说明改变定义。 | 前文“智能体＝可调用工具的系统”，后文“智能体＝任何聊天窗口”。 | 概念边界漂移会破坏全书方法体系。 |
| B51 | 禁止同一术语、同一对象在前后文中无依据地改名。 | 前文“研究任务卡”，后文“科研行动表”，实为同一模板。 | 读者误以为出现了新工具或新环节。 |
| B52 | 禁止同一案例的机构、人物、时间、费用、数据或背景前后不一。 | 前文“某校30名教师”，后文“该校50名学生参与”。 | 对象类型和样本人数发生不明变化。 |
| B53 | 禁止案例开头提出的任务在中段被无解释替换。 | 以“优化课程评价”为题，演示却转成“生成海报”。 | 任务主线中断，案例无法验证原目标。 |
| B54 | 禁止操作步骤出现依赖未执行步骤的情况。 | 第2步“选择刚刚创建的知识库”，而第1步未创建知识库。 | 前置条件缺失，导致流程不可运行。 |
| B55 | 禁止用“前文已讲”“见下一节”等指向实际上不存在的内容。 | “上一节已经介绍了四种方法”，上一节只有两种。 | 篇章承诺与实体内容不一致。 |
| B56 | 禁止标题、导语、正文、结尾讲述不同的问题。 | 标题“如何识别错误”，正文大半篇只介绍工具价格。 | 章节功能错位，核心问题没有展开。 |
| B57 | 禁止承诺列举数量与实际列举数量不符。 | “下面介绍五个原则”，只列四项。 | 结构自相矛盾，造成明显缺项。 |
| B58 | 禁止同一层级的列表项彼此包含、重复或分类标准变化。 | “①教学场景；②高校教学；③营销；④软件”。 | 类别交叉且颗粒度混杂，无法形成有效分类。 |
| B59 | 禁止从描述现象直接跳到因果机制、方案或价值判断，中间缺少必要论证。 | “员工常加班，因此企业必须采购某款软件。” | 现象不能独立支持特定解决方案。 |
| B60 | 禁止结论强于前文证据允许的程度。 | 前文仅有一组问卷，结尾“已彻底解决行业难题”。 | 结论范围从局部数据扩张到整个行业。 |
| B61 | 禁止章节内部反复重新定义问题而没有增加分析维度。 | 第一段、第三段和结尾分别解释一遍“什么是判断力”。 | 同一层次内容多次占位，进展中断。 |
| B62 | 禁止用前文已被否定的条件支撑后文建议。 | 前文“离线环境不能调用该接口”，后文“离线时直接调用该接口”。 | 前后操作条件互相矛盾。 |
| B63 | 禁止对同一行动的权限、风险分级或责任主体作相互冲突的规定。 | 第2章“用户批准后方可发送”，第5章“完全自动发送，无须审批”。 | 全书规则冲突会产生实际使用风险。 |
| B64 | 禁止把结尾变成与章节目标无关的行业宏观宣言。 | 一节讲“校对表格”，收尾突然讨论“民族复兴的历史使命”。 | 话题跳变超出本节论证边界。 |
| B65 | 禁止人物称谓、人称视角和时间叙述无标记切换。 | 同一段先写“我测试了”，后写“作者认为”，又写“我们团队发现”。 | 叙述身份不稳定，容易造成来源和视角混乱。 |
| B66 | 禁止相邻段落间缺少语义承接且又出现重大话题跳跃。 | 上段讨论版权授权，下段突然讨论备课时间，未交代关系。 | 读者无法识别观点之间的联系。 |
| B67 | 禁止同一判断在不同章节使用互相冲突的评价标准。 | 第3章以准确率评价质量，第4章仅以生成速度宣布同一系统“更优”。 | 指标切换导致全书结论不可比较。 |

## B6．字词、标点、数字与书写规范

| 编号 | 禁止事项 | 违规示例 | 违规原因与判定说明 |
|---|---|---|---|
| B68 | 禁止错别字、形近字误用及不符合语境的同音替换。 | “按部就班”写成“按步就班”；“截至”误写为“截止”（语义需要“截至”时）。 | 字形相近但意义和语法职能不同。 |
| B69 | 禁止中文叙述中无特殊用途地混入英文半角句号、逗号、分号、冒号。 | “结果如下:甲,乙,丙.” | 正文标点系统混杂；URL、代码、公式和英文原文不属于此类错误。 |
| B70 | 禁止引号、括号、书名号缺少配对或嵌套层级混乱。 | “《人工智能入门》”“《第一章”。 | 结构性标点不闭合，破坏句法边界。 |
| B71 | 禁止逗号切断紧密的主谓、动宾或定中结构。 | “编辑让软件，自动检查错别字。” | 无语义停顿依据的分割造成句法破裂。 |
| B72 | 禁止顿号、逗号、分号混用而改变并列层级。 | “研究对象包括教师、学生；平台、工具、技术。”（类别关系未说明） | 并列层次及分组依据不清。 |
| B73 | 禁止冒号所引内容与提示语范围不一致。 | “主要有三项：内容质量、编辑效率。” | 冒号后的枚举与前面的数量提示矛盾。 |
| B74 | 禁止无依据使用破折号代替句法关系，制造句子断裂。 | “这项工作——能够提高审批效率——非常重要。” | 多余插入打断主干，误导逻辑重心。 |
| B75 | 禁止省略号与“等”“等等”在同一枚举末尾重复表达省略。 | “文字、图片、视频等等……” | 省略标记叠加，语义功能重复。 |
| B76 | 禁止标点与引用句末关系混乱，改变被引内容完整性。 | 把原文未完句截断却添加句号并标注为完整直引。 | 引文边界和原文语义不一致。 |
| B77 | 禁止数学符号、货币单位、温度、百分号及计量单位前后不统一。 | 同一成本表中混写“元／万元”但没有标识；将“5%”写成“5个百分点”。 | 单位和增长率概念错置会直接改变计算意义。 |
| B78 | 禁止把百分比、百分点、倍数、增长量、增长率混为一谈。 | “从10%升至15%，增加了5%。” | 绝对百分点变化与相对百分比变化不同。 |
