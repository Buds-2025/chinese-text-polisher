# C级清单｜风格禁用与高风险表达：绝对化、套话、黑话和机械文风

> 本文件是 chinese-text-polisher 技能的 C 级排查分册。C 级多为风格约束与高风险表达，其中部分属于本项目定制禁句（不是通用语法错误）；“规避”不等于所有语境均禁止，须结合命题范围、证据和文体判定。
>
> 目录：
>
> - C1 本项目明确禁用的句式、口头禅与表达（C01–C12）
> - C2 绝对化表述、夸大宣传与范围失控（C13–C28）
> - C3 开篇、过渡、结尾的模板化套话（C29–C42）
> - C4 重复论证、信息空转与形式化组织（C43–C52）
> - C5 大厂黑话、术语滥用与伪概念（C53–C62）
> - C6 修辞、比喻和语言语感失当（C63–C71）
> - C7 作者姿态、读者关系与叙述视角（C72–C81）

## C1．本项目明确禁用的句式、口头禅与表达

| 编号 | 禁止事项 | 违规示例 | 违规原因与判定说明 |
|---|---|---|---|
| C01 | 禁止使用“不是……而是……”及近似二元反转句式。 | “这不是一次效率提升，而是一场认知革命。” | 以形式上的强对立替代具体分析；包括“并非……而是……”“问题不在……而在……”“与其说……不如说……”的机械套用。 |
| C02 | 禁止使用“真正……的是……”及近似强行揭示本质的句式。 | “真正重要的，是认知升级。”“真正值得关注的不是速度。” | 预设前文观点浅薄，以揭晓式语气制造并不存在的深刻性。 |
| C03 | 禁止用“首先／其次／最后”机械组织普通论述。 | “首先提升认知，其次优化流程，最后形成闭环。” | 列表化过渡词冒充严密结构；本项目属于定制禁句，不是通用语法错误。 |
| C04 | 禁止以“想象一下／试想一下”直接命令读者进入虚构情境。 | “想象一下，十年后的世界会怎样？” | 依赖读者自行补全场景，削弱具体信息。 |
| C05 | 禁止“说白了／讲真／说实话／恕我直言”等自我标榜直率的口头禅。 | “说白了，你不会用工具。” | 无事实增量，易形成轻慢或说教姿态。 |
| C06 | 禁止“很多人一开始／很多人第一次”作为无依据的惯用开场。 | “很多人一开始都把AI当成搜索框。” | 擅自概括群体行为，且高度模板化。 |
| C07 | 禁止用“有点轻／有点硬／太虚／不够实”等模糊词替代具体批评。 | “这一节有点轻，逻辑有点硬。” | 评价标准不明，读者无法判断具体缺陷。 |
| C08 | 禁止未限定语境的“接住／落盘／打法／最稳”等行业口头黑话。 | “接住这波需求，再把经验落盘。” | 内部工作语言进入公开出版物，带来歧义和阅读门槛。 |
| C09 | 禁止“别急／先别慌／让我们暂停一下”等无必要的心理引导开头。 | “别急，我们先来拨开迷雾。” | 擅自预设读者情绪，延缓进入问题。 |
| C10 | 禁止“我敢说／我必须强调／请记住这句话”等以说话者气势代替证据。 | “我敢说，未来所有岗位都将改变。” | 主观确信被包装成论据。 |
| C11 | 禁止“你只需要……就能……”式低估成本的保证性句式。 | “你只需要输入一句话，就能完成完整科研。” | 隐去任务边界、人工审查和失败条件。 |
| C12 | 禁止“从此告别……／彻底摆脱……”等营销式问题消失宣言。 | “从此告别所有写作难题。” | 将改善局部环节夸大为永久解决。 |

## C2．绝对化表述、夸大宣传与范围失控（重点增补）

| 编号 | 禁止事项 | 违规示例 | 违规原因与判定说明 |
|---|---|---|---|
| C13 | 规避“所有／任何／全部／每个／人人／无一例外”的无依据全称判断。 | “所有高校教师都需要掌握这项技术。” | 全称命题只需一个反例即可失效；应重点检查总体范围是否被证明。 |
| C14 | 规避“永远／从来／绝不／再也不会”的无限时域判断。 | “这类工具永远不会失效。” | 时间范围无限延伸，未来变化无法由当前事实保证。 |
| C15 | 规避“一定／必然／必定／毫无疑问／毋庸置疑”的无证据确定性判断。 | “掌握这个框架一定能取得高分。” | 将概率性效果表述成确定结果。 |
| C16 | 规避“唯一／仅有／只有这条路／别无选择”的排他性断言。 | “这是企业数字化转型的唯一方案。” | 排除所有替代路径需要极强证据。 |
| C17 | 规避“最／第一／顶级／最佳／史上最强／行业第一”等缺少比较依据的极值称号。 | “这是目前最准确的文本模型。” | 极值必须依赖明确集合、时点与测量指标。 |
| C18 | 规避“完美／彻底／完全／全面解决／一劳永逸”的无保留效果宣称。 | “本方法可以彻底消除沟通误差。” | 现实过程存在残余误差、例外与变化。 |
| C19 | 规避“100%／百分之百／零错误／零风险／绝对安全”的无依据零容差保证。 | “该方案的输出准确率为100%。” | 若无严格场景、样本与验证条件，绝对数字具有误导性。 |
| C20 | 规避“零成本／零门槛／无须学习／人人上手”的隐性成本抹除。 | “这套系统零成本，任何人五分钟都能掌握。” | 忽略时间、设备、订阅、能力差异和维护成本。 |
| C21 | 规避“无限／无上限／永不收费／永久可用”的未受合同保障的产品承诺。 | “该接口提供永久免费、无限调用。” | 服务和条款可能变动，且“无限”常受实际限额约束。 |
| C22 | 规避“必胜／稳赚／保证录用／包过／必涨”等结果性保证。 | “照着这个方法写，一定能拿到项目。” | 结果取决于多个不可控变量，承诺超出作者控制范围。 |
| C23 | 规避“颠覆一切／改变所有行业／重塑整个人类社会”等无边界宏大判断。 | “一款软件将彻底改写全部文明规则。” | 抽象对象和影响范围过大，无法形成可检验命题。 |
| C24 | 规避“公认／众所周知／人人都知道／全行业一致认可”的无来源共识断言。 | “业内公认，所有智能体都优于传统软件。” | 虚构一致意见，掩盖争议与例外。 |
| C25 | 规避“显著／大幅／成倍／飞跃式／指数级”的无量化依据增长形容。 | “学习效率指数级提升。” | “指数级”具有特定数学含义，不等同于“增长较快”。 |
| C26 | 规避“无可替代／不可撼动／压倒性优势”等未规定比较维度的强评价。 | “这个平台具有不可替代的竞争优势。” | 缺少替代对象和评价准则，判断无法证伪。 |
| C27 | 规避用“必须／严禁／一律”对不具强制效力的普遍建议作命令。 | “所有读者必须采用这个提示词模板。” | 将方法偏好提升为强制规范，混淆适用性质。 |
| C28 | 禁止把本身有确定范围的合法全称命题误判成绝对化病句。 | 因出现“所有”就删除“所有三角形的内角和在欧氏平面上等于180°”。 | “绝对化”问题取决于命题范围和证据，不取决于词语本身。 |

## C3．开篇、过渡、结尾的模板化套话

| 编号 | 禁止事项 | 违规示例 | 违规原因与判定说明 |
|---|---|---|---|
| C29 | 禁止以“在当今……时代／在……浪潮下／随着……快速发展”空泛开篇。 | “在数字化浪潮席卷全球的今天，效率变得越来越重要。” | 抽象背景无法解释本节的具体问题。 |
| C30 | 禁止“前所未有／日新月异／深刻变革／时代洪流”等宏大套语密集堆积。 | “新技术以前所未有之势掀起深刻变革的浪潮。” | 多个同义形容词仅制造气势，不增加信息。 |
| C31 | 禁止“值得一提的是／需要指出的是／不难发现”等无必要过渡。 | “值得注意的是，下一步要保存文件。” | 话语提示替代事实衔接，阅读效率低。 |
| C32 | 禁止“由此可见／综上所述／总而言之”后仅复读原文。 | “综上所述，掌握方法非常重要。” | 总结缺少新判断或有效归纳。 |
| C33 | 禁止“这不仅是……更是……”式无证据抬高意义。 | “这不仅是一次备课，更是教育文明的跃迁。” | 将具体行为强行升级到宏大概念。 |
| C34 | 禁止“这意味着／归根结底／从本质上讲”后陈述无法从前文推出的结论。 | “学生参与了讨论，这意味着课程改革已经成功。” | 用话语信号伪装逻辑推导已经完成。 |
| C35 | 禁止段落开头连续使用“我们知道／大家都知道／相信大家”。 | “大家都知道，模型一定不会犯低级错误。” | 预设共同认知，掩盖事实待证性。 |
| C36 | 禁止“核心中的核心／关键中的关键／本质上的本质”等词语叠高。 | “核心中的核心是认知层面的底层核心。” | 强调的形式重复，概念内容空缺。 |
| C37 | 禁止以“总结为三大法宝／四大密码／五个秘诀”替代清晰分类。 | “让你成功的五大终极心法。” | 标题先行，论证后补，容易制造虚假体系。 |
| C38 | 禁止在每个小节机械重复“提出问题—三点罗列—拔高总结”同一模板。 | 连续六节都以“为什么重要”开头、以“未来可期”收尾。 | 章法被格式接管，不同知识点的功能被抹平。 |
| C39 | 禁止无意义的设问自答和假装悬念。 | “那么，答案究竟是什么？其实非常简单。” | 让读者等待却没有实际推理任务。 |
| C40 | 禁止在正式正文中强行插入“今晚就做这件事”等固定营销化收尾。 | 每节结尾均出现“今晚马上行动起来！” | 固定号召与章节内容脱钩，造成口号式重复。 |
| C41 | 禁止以“未来已来／机会属于行动者／让我们拥抱变化”作为知识性结尾。 | “未来已来，让我们共同奔赴新时代。” | 泛化情绪收束无法回应具体论题。 |
| C42 | 禁止连续以“第一个层面／第二个层面／第三个层面”人为制造结构层级。 | “第一个维度是认知，第二个维度是思维，第三个维度是意识。” | 各维度缺乏区别，分类只剩命名。 |

## C4．重复论证、信息空转与形式化组织

| 编号 | 禁止事项 | 违规示例 | 违规原因与判定说明 |
|---|---|---|---|
| C43 | 禁止同一观点在开头、正文、结尾连续换词重复。 | “判断力很重要”“必须提高判断能力”“判断能力决定成功”。 | 多次表达同一结论，缺少证据、条件和机制增量。 |
| C44 | 禁止用相近抽象词互相解释。 | “认知升级就是思维升级，思维升级意味着能力升级。” | 同义循环无法提供可操作含义。 |
| C45 | 禁止为凑字数堆叠并列近义词。 | “不断提高、持续提升、全面增强工作能力。” | 词语数量增加但谓语信息不变。 |
| C46 | 禁止把一条完整逻辑人为拆成数条同义标题。 | “提高效率”“提升产出速度”“减少工作耗时”分别成节。 | 章节互相蚕食，结构冗余。 |
| C47 | 禁止每段都有一条“金句”而缺少普通事实与论证。 | “工具是翅膀，认知是天空，行动是答案。” | 结论性修辞过密，具体解释缺席。 |
| C48 | 禁止只有主张和口号，没有真实机制、例证或限定的论证。 | “组织要建立创新文化，打造高效协同生态。” | 读者无法检验该主张为何成立。 |
| C49 | 禁止一个段落塞入彼此不相干的多个中心。 | 先讲股权，再讲海报设计，末尾突然讨论学习心理。 | 段落主题漂移，论证关系被切断。 |
| C50 | 禁止将自然复杂问题压成无条件的“三步成功法”“万能公式”。 | “任何教材都能按三步法获得国家级奖项。” | 模型范围失控，掩盖制度条件、情境差异和失败路径。 |
| C51 | 禁止整章只罗列“重要性／价值／意义”，缺少对象、过程、边界等实质内容。 | 每节均为“可以提升效率、优化体验、促进创新”。 | 形式结构完成，实际知识交付不足。 |
| C52 | 禁止把局部判断不断升格成组织、行业、时代的普遍命题。 | 从“编辑节约10分钟”跳到“整个出版业发生根本革命”。 | 论证尺度越级，缺少中间证据。 |

## C5．大厂黑话、术语滥用与伪概念

| 编号 | 禁止事项 | 违规示例 | 违规原因与判定说明 |
|---|---|---|---|
| C53 | 规避“赋能／抓手／闭环／对齐／拉齐／发力”在一般叙述中的空泛套用。 | “以协同抓手赋能编辑全流程，形成能力闭环。” | 不能清楚交代主体、动作、对象及结果。 |
| C54 | 规避“底层逻辑／顶层设计／认知跃迁／价值进化”未经定义的大词堆叠。 | “推动底层逻辑重构和价值认知跃迁。” | 抽象层次很高，具体含义缺失。 |
| C55 | 规避“颗粒度／心智／调性／链路／矩阵／背书／打法／解法”脱离专业语境的泛化。 | “提升内容颗粒度，建立转化心智矩阵。” | 术语来源不同，被拼接后失去明确所指。 |
| C56 | 禁止临时发明名词，却把它包装成既有学术模型或行业标准。 | “国际通行的七维流量跃迁模型”。 | 来源和知识地位被伪造。 |
| C57 | 禁止为普通动作强行命名为“××法则／××引擎／××飞轮”。 | “点击保存的底层动作遵循三重确认飞轮。” | 概念化超过知识本身复杂度，增加理解负担。 |
| C58 | 禁止同一个概念出现多个未解释的英文缩写或中英文译名。 | “行动代理／执行智能体／AA／agent runner”交替指同一对象。 | 术语系统不稳定。 |
| C59 | 禁止用陌生英文词、首字母缩写替代已明晰的常用汉语。 | “做好alignment后，执行delivery。” | 增加无意义的语言转换成本。 |
| C60 | 禁止把技术术语作超范围比喻使用并模糊本义。 | “任何组织交流都可以定义为神经网络反向传播。” | 不同领域概念映射过度，可能带来事实误解。 |
| C61 | 禁止用术语数量冒充论述深度。 | 一段中堆积“RAG、MCP、MoE、RLHF”却不说明与任务的关系。 | 名词增加没有解释力，反而中断知识传递。 |
| C62 | 禁止将未经证实的个人分类体系写成普适、权威、标准化框架。 | “所有科研都必须遵循这个六阶段国际标准。” | 私有整理成果与公共学术共识混淆。 |

## C6．修辞、比喻和语言语感失当

| 编号 | 禁止事项 | 违规示例 | 违规原因与判定说明 |
|---|---|---|---|
| C63 | 禁止不符合实际概念关系的生硬比喻。 | “参考文献是论文的血管，评审意见是它的发动机。” | 意象和功能关系无法对应。 |
| C64 | 禁止同一段内频繁切换互不兼容的比喻系统。 | “知识是种子，流程是引擎，评价又是航道。” | 读者需要不断重新建立映射，逻辑负担上升。 |
| C65 | 禁止以战争、航海、生态、宇宙等大意象装饰平常操作。 | “打开菜单，吹响编辑效率战役的冲锋号。” | 修辞强度与任务性质失衡。 |
| C66 | 禁止将拟人、拟物写成技术事实。 | “系统会主动理解你的真实愿望，并永不背叛。” | 拟人化措辞暗示未经证明的能力。 |
| C67 | 禁止连续对仗、四字格与口号式排比掩盖空洞信息。 | “认知破局、效率突围、价值升维、生态共赢。” | 形式整齐但缺少可验证内容。 |
| C68 | 禁止为了押韵或新奇而破坏汉语的自然搭配。 | “把需求问成答案，把结果写出未来。” | 谓宾关系和逻辑对应缺乏自然语义。 |
| C69 | 禁止无实际例证的“说人话式”夸张口语。 | “这玩意儿简直神了，谁用谁知道。” | 表达随意且不可核验。 |
| C70 | 禁止对日常工作进行夸张的戏剧化描写。 | “一个标点的失误，足以掀翻整个商业帝国。” | 事实严重程度被不合理放大。 |
| C71 | 禁止以缺少定义的“高／低／深／浅／硬／软／轻／重”替代评价维度。 | “这个框架层次很高，但操作太软。” | 形容词没有可复核的测量尺度。 |

## C7．作者姿态、读者关系与叙述视角

| 编号 | 禁止事项 | 违规示例 | 违规原因与判定说明 |
|---|---|---|---|
| C72 | 禁止无证据地替读者判断知识水平、感受与动机。 | “你肯定还没弄懂这个基本概念。” | 强行预设读者状态，损害作者与读者的平等关系。 |
| C73 | 禁止居高临下的指责与羞辱。 | “还在这样做的人，说明思维已经落后了。” | 把知识差异转化为人格评价。 |
| C74 | 禁止防御性解释读者尚未提出的质疑。 | “我这么说不是看不起你，也不是说你笨。” | 凭空引入敌意，干扰正常论证。 |
| C75 | 禁止以作者的勤奋、经验、权威地位代替研究证据。 | “我做这行二十年了，所以这条结论绝对正确。” | 身份资历不能自动证明命题。 |
| C76 | 禁止擅自把“我”的经历扩写为未发生的试错、成功或客户服务故事。 | “记得有一次，我亲手挽救了一个濒临失败的项目。” | 第一人称提高真实性期待，虚构风险更高。 |
| C77 | 禁止在客观教材里无必要地频繁插入“我认为／我建议／我发现”。 | “我觉得这个公式成立，我建议大家相信它。” | 作者态度挤占知识论证空间。 |
| C78 | 禁止面向陌生公众时不解释身份便使用“我们团队／我们内部／我们公司”。 | “我们内部一直用这个模板。”（机构身份从未出现） | 读者无法识别“我们”的所指与证据权限。 |
| C79 | 禁止在未获得授权、未界定所指时替机构、同行或所有读者发言。 | “我们所有高校都认为这项改革已经成功。” | 集体发言范围不实。 |
| C80 | 禁止频繁使用自问自答、命令和情绪催促操控阅读节奏。 | “记住！现在立刻照做！还不懂就再看一遍！” | 语言压力高于内容所需。 |
| C81 | 禁止过度亲昵、戏谑和嘲讽式称呼出现在正式教材语境。 | “各位小可爱，赶紧拿捏这波知识点。” | 语域与正式教学用途不匹配。 |
