# D级清单｜场景专项规避：教材、操作手册、图表与出版体例

> 本文件是 chinese-text-polisher 技能的 D 级排查分册。D 级按相应文体、章节及交付要求判定，适用于教材正文与案例、软件教程、图表公式说明、稿件体例以及全书统一性审校。
>
> 目录：
>
> - D1 教材内容、案例与教学任务（D01–D12）
> - D2 软件教程、界面指令和技术环境（D13–D27）
> - D3 图、表、公式和图文对应关系（D28–D42）
> - D4 稿件体例、段落与书面表现（D43–D56）
> - D5 全书统一性、审校盲区和边界混淆（D57–D64）

## D1．教材内容、案例与教学任务

| 编号 | 禁止事项 | 违规示例 | 违规原因与判定说明 |
|---|---|---|---|
| D01 | 禁止案例与该章知识目标无关，仅靠场景热闹撑篇幅。 | “学习股权结构”却以“如何设计课程海报”作为完整主案例。 | 场景与教学目标错配，学生无法从案例中获得目标知识。 |
| D02 | 禁止把例题结论直接当作推导过程。 | “由上述数据可知答案为42。”（没有任何运算过程） | 对需要演算的学习任务形成步骤断层。 |
| D03 | 禁止练习题依赖正文从未介绍且无法合理推得的知识。 | 正文只讲术语定义，练习要求独立搭建复杂系统。 | 任务难度与前置知识不匹配。 |
| D04 | 禁止情境案例的角色、设备、预算、时间与行业常识明显冲突。 | “三人初创团队当天建成全国性物流网络。” | 案例内部条件不足以支撑行动结果。 |
| D05 | 禁止伪造课堂实施记录、学生反馈和教学成效。 | “试用后全班学习成绩均提升30%。”（没有真实记录） | 把教学设计推想当作实践证据。 |
| D06 | 禁止“概念—概念”的解释连锁，使基础概念始终落不到明确对象。 | “项目管理就是流程治理，流程治理就是组织协同。” | 循环定义缺少可判别内容。 |
| D07 | 禁止同一章节先要求读者学会工具，又把该工具的前置知识放在后文且没有衔接。 | 第1节要求配置API，第4节才解释密钥和基础网址。 | 教学认知顺序颠倒。 |
| D08 | 禁止习题、任务与答案使用不同的条件或参数。 | 题目给出税率3%，答案按6%计算。 | 演算依据不一致，影响学习结果判定。 |
| D09 | 禁止把不同专业、学段或读者群的能力要求混写为同一默认前提。 | 面向零基础中职学生，默认已会配置容器集群。 | 读者前置能力假设与实际定位冲突。 |
| D10 | 禁止把未经论证的个人主张称为国家标准、学科定论或高校统一要求。 | “国家规定所有创新创业课必须采用六维创业能力模型。” | 将教学建议错误提升到制度层级。 |
| D11 | 禁止思考题仅重复“谈谈体会／谈谈认识”，且与知识目标脱节。 | 一整节五道题全部为“谈谈你的理解”。 | 题目无法区分事实掌握、应用能力与分析能力。 |
| D12 | 禁止章节标题宣称“实战”，正文却只有价值论述而无真实任务、材料或执行环节。 | “实战搭建科研助手”，正文只写“科研助手意义重大”。 | 标题对教学用途作出未兑现的承诺。 |

## D2．软件教程、界面指令和技术环境

| 编号 | 禁止事项 | 违规示例 | 违规原因与判定说明 |
|---|---|---|---|
| D13 | 禁止用“点击”笼统指代会改变操作结果的不同交互动作。 | 需要右击弹出菜单，却写“点击目标文件”。 | 单击、双击、右击、长按等具有不同结果。 |
| D14 | 禁止把鼠标、触屏、键盘、命令行操作混写成同一动作。 | 在手机教程中写“鼠标悬停菜单项”。 | 输入设备和交互模型不匹配。 |
| D15 | 禁止仅用颜色、像素位置或图标顺序定位关键控件。 | “点击屏幕右上方第三个蓝色按钮。” | 界面主题、布局及版本更新后定位失效。 |
| D16 | 禁止在不同版本软件间混用菜单名、功能名、路径和快捷键。 | 以旧版截图说明新版已移除的“导出到本地”按钮。 | 操作路径无法复现。 |
| D17 | 禁止把平台功能状态写成无版本、无地区或无账号限制的普遍能力。 | “所有账号都能直接调用该功能。” | 账号等级、地域、客户端和产品版本会改变可用性。 |
| D18 | 禁止编造未经验证的菜单项、功能入口、快捷键或命令参数。 | “按Ctrl＋Shift＋E可直接备份全站数据。”（并无此快捷键） | 操作说明的可执行性被破坏。 |
| D19 | 禁止把示意性命令写成可直接运行的完整命令。 | `curl https://example.invalid/api -H 'Key: your-key'` 却宣称“直接执行即可成功”。 | 占位值不满足执行条件，示例性质未区分。 |
| D20 | 禁止在代码、URL、JSON、API参数和文件路径中随意使用中文标点或更改大小写。 | 把JSON的英文双引号写为中文双引号。 | 机器可解析语法不能按中文出版标点规则改写。 |
| D21 | 禁止省略操作前提却呈现“单击即得”的流程。 | “打开终端运行命令即可。”（依赖的软件和权限并不存在） | 环境条件缺失，流程无法复现。 |
| D22 | 禁止省略具有重大后果的权限、费用、数据覆盖或不可逆操作风险。 | “直接清空数据库，完成环境重置。” | 可能造成数据损失或超预期支出。 |
| D23 | 禁止把工具的试用结果扩张为稳定可用性保证。 | “我试过一次成功，所以任何环境都不会报错。” | 单次测试不能排除版本差异、网络环境和异常输入。 |
| D24 | 禁止将模型生成的文本、执行命令的结果和人工操作混为同一种交付状态。 | “模型输出了备份命令，所以资料已经备份。” | 提供指令与实际执行之间存在不可省略的动作差异。 |
| D25 | 禁止将截图中看不到的界面元素描述为已存在。 | “如图所示，右侧有四个设置选项。”（图中只有两个） | 图文指向互相矛盾。 |
| D26 | 禁止教程流程无条件依赖联网、付费服务或第三方权限，却声称“离线免费完成”。 | “全程无需网络”，步骤却调用在线模型API。 | 前提和方法冲突。 |
| D27 | 禁止将示例密钥、密码或账户信息写为真实可公开复用的凭证。 | “所有读者使用同一个管理员密钥即可。” | 安全权限和账户隔离失效。 |

## D3．图、表、公式和图文对应关系

| 编号 | 禁止事项 | 违规示例 | 违规原因与判定说明 |
|---|---|---|---|
| D28 | 禁止正文承诺“如图／如下表”却没有对应的图表实体。 | “见图3-5”，正文及图目录均无图3-5。 | 证据和阅读定位缺失。 |
| D29 | 禁止图题、表题与图表内容不符。 | 表题“年度收入”，表内却全是成本数据。 | 读者会对图表含义产生错误理解。 |
| D30 | 禁止图号、表号重复、跳号、跨章错号或正文引用号不一致。 | 同章出现两张“图2-4”，正文还引用“图2-6”。 | 编号不再具有唯一定位功能。 |
| D31 | 禁止图表内外的名称、数据、单位、时间或类别不一致。 | 正文说“3类风险”，图示却出现5类且名称不同。 | 图文无法互相验证。 |
| D32 | 禁止用无数据依据的面积、长度、角度或颜色深浅暗示数值关系。 | 两个柱形高度相差一倍，实际数值仅差10%。 | 视觉编码扭曲数量对比。 |
| D33 | 禁止有方向含义的箭头与文字中的因果、流程或层级关系相反。 | 图示“结果→输入”，正文解释为“输入产生结果”。 | 图示逻辑结构错误。 |
| D34 | 禁止流程图形成死循环、悬空节点、缺少必要出口而不解释。 | “提交→审核→通过→审核”且无完成节点。 | 流程不可终止或责任流向不明。 |
| D35 | 禁止用集合包含图表示互不包含的分类关系。 | “高中教师”被画成“大学教师”的子集。 | 图形拓扑关系本身表达错误命题。 |
| D36 | 禁止用示意图冒充真实产品截图、实验照片或现场证据。 | “平台实测截图”实际为自行绘制的概念界面。 | 图像证据属性被错误标注。 |
| D37 | 禁止图中文字出现错别字、失真汉字、错误符号或无法辨认的标签。 | 流程节点标为“校对→校兑→发布”。 | 视觉美观不能抵消文字和知识错误。 |
| D38 | 禁止图注、图题、数据来源与真实来源性质不符。 | 自拟流程图标注“来源：某国际标准”。 | 来源被冒认，图表知识地位遭到抬高。 |
| D39 | 禁止表格中不同计量单位的数据在同一列直接比较而不标识。 | “营收：50万元”“成本：8000元”，标题却统一标为“金额（万元）”。 | 量纲不一致导致对比失真。 |
| D40 | 禁止公式符号不定义、前后复用为不同含义或计算结果错误。 | 前文X表示样本量，后文X突然表示利润且无说明。 | 数学表达的变量语义不稳定。 |
| D41 | 禁止以美观为由删去解释逻辑所必需的节点、条件和数据标签。 | 风险决策图只保留“是／否”，删除判断问题。 | 图形失去独立理解条件。 |
| D42 | 禁止图表只重复标题，没有提供额外结构、比较或证据。 | 图题“流程分为三步”，图内只有“三步”二字。 | 图示不承担独立信息功能。 |

## D4．稿件体例、段落与书面表现

| 编号 | 禁止事项 | 违规示例 | 违规原因与判定说明 |
|---|---|---|---|
| D43 | 禁止把固定句长上限冒充现代汉语语法强制标准。 | “任何超过40字的句子都属于病句。” | 句子是否有语病取决于结构和意义，不能仅按字数断定。 |
| D44 | 规避堆叠多层定语、插入语和从句导致句义难以追踪。 | 一句话同时交代五个身份、四个条件和三个结果。 | 句法虽可能成立，但工作记忆负担过高。 |
| D45 | 禁止把单段120～250字、每段2～4句等经验阈值当作所有文体的硬规定。 | “任何只有一句话的段落一律删除。” | 对话、定义、警示、转折和节奏性短段可能有合法功能。 |
| D46 | 规避连续多段“一句一行”却没有对话、操作、节奏或强调功能。 | 十几个相邻段落每段只有一句空泛观点。 | 内容被无意义切碎，削弱篇章连贯性。 |
| D47 | 规避多段长度、句法、开头和结尾高度机械对称。 | 连续十段均为三句、同字数、同样以“因此”收尾。 | 形式过于整齐，可能掩盖不同知识内容的自然差异。 |
| D48 | 规避破折号、感叹号、省略号、引号的高密度装饰性使用。 | “终于——效率革命来了！！！” | 特殊标点制造虚假情绪强度或不必要断裂。 |
| D49 | 禁止将破折号单节8次、感叹号千字0.3次等偏好阈值写成国家出版强制规定。 | “破折号出现9次，即违反国家标点标准。” | 固定次数通常只是项目风格约束，并非普适法规。 |
| D50 | 规避无必要的大面积加粗、斜体、彩色强调和多重标记。 | 一整段每句话均加粗，且叠加引号、感叹号。 | 层级重点消失，版式信息噪声增多。 |
| D51 | 禁止同级标题无理由地混用句式、标号和概念层级。 | “一、选题原则”“二、如何选题”“三、好书的未来”。 | 平行层级功能不对应，目录结构失衡。 |
| D52 | 禁止不同层级标题编号相互冲突。 | “2.1”下直接出现“3.1.2”。 | 章节从属关系被破坏。 |
| D53 | 禁止使用双重编号或标题文本与目录不一致。 | 目录“4.2 案例分析”，正文“4.3 案例分析”。 | 检索与交叉引用定位出错。 |
| D54 | 禁止在中文出版稿中无语义依据地混入简繁体、全半角及中英文空格。 | “本 章 将 深 入 讨 论 A I 应 用 。” | 版面残留或机械分词痕迹干扰阅读；公式、单位、外文专名另论。 |
| D55 | 禁止把非规范的Markdown控制字符、HTML标签或导出标记留在正式正文。 | “## 第二节”“<div>案例</div>”“```markdown”。 | 标记语言未经排版转换，破坏终稿形态。 |
| D56 | 禁止机械规定“我”每千字必须出现某个次数、每节必须有“你／我们”。 | “这节只有6个‘我’，必须补到8个。” | 人称频次不能证明内容真实性或叙述自然性。 |

## D5．全书统一性、审校盲区和边界混淆

| 编号 | 禁止事项 | 违规示例 | 违规原因与判定说明 |
|---|---|---|---|
| D57 | 禁止不同章节反复使用完全相同的虚构案例、设定和数字却未说明沿用关系。 | 第2、5、8章均突然出现“某企业一周省下70%成本”。 | 内容重复且容易制造虚假的经验丰富度。 |
| D58 | 禁止章节难度、读者称谓、术语深度无缘由地剧烈变化。 | 入门章节直接进入多模态模型训练细节，后文又解释什么是文件夹。 | 知识梯度失序，读者定位不稳定。 |
| D59 | 禁止仅检查正文，放过图表文字、表头、注释、脚注、练习答案和目录中的错误。 | 正文术语正确，图中却使用另一套错误名称。 | 错误仍通过其他版面元素进入成品。 |
| D60 | 禁止以词表机械搜索结果替代对上下文的判断。 | 看到“必须”一律删除，连法律规定和安全警示也删掉。 | 将风格筛查与事实性、规范性约束混为一谈。 |
| D61 | 禁止把无来源的个人经验统计写成经验证的行业概率。 | “我观察过几个项目，所以80%的企业都会失败。” | 从经验印象跳到人口总体比例。 |
| D62 | 禁止将章节内部的“示例”“假设”“数据演示”在后文重新称为“真实案例”“实测结果”。 | 第1节标注虚构，第4节改称“真实业务证明”。 | 证据属性跨章节漂移。 |
| D63 | 禁止把含有教学目的的“提示词”“AI模型”等正常知识术语误判为幕后生成痕迹。 | 在讲授提示词的教材中，删除“提示词示例”标题。 | 成品诚信约束针对制作过程泄露，不针对书籍研究对象。 |
| D64 | 禁止为了“去模板感”而删除本来必需的定义、结构、引用和安全边界。 | 因为表格“太整齐”而删除全部条件说明。 | 风格修订不应制造信息缺失或知识错误。 |
